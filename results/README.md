# Results and Visualisations

This directory contains selected visualisations and evaluation outputs from the Intelligent Rehabilitation System project.

## Contents

- **Confusion Matrices:** Comparison of predicted and actual muscle-activation categories for the evaluated machine-learning models.
- **Model Comparison:** Comparison of Random Forest, Support Vector Machine (SVM), and Decision Tree performance using accuracy and balanced accuracy.
- **Feature Importance:** Visualisation of the contribution of input features to model predictions, where applicable.

## Interpretation

The results represent preliminary model evaluations using window-level EMG features. The activity labels were generated using an RMS-ratio threshold and are not clinically validated.

The reported metrics should therefore be interpreted cautiously. They do not establish clinical diagnostic accuracy or generalisation to unseen participants.

See the main [README](../README.md) for the project overview, methodology, reported metrics, and limitations.
